2026-03-25 项目创建

第一次有写博客的想法大概是在24年，那时候是大三，林林总总学了一些计算机相关的知识，有很多想学的、感兴趣的，但是实际坚持下来学会的没几个，总是三分钟热度。。。

当时好像是看来B站up主Letere-莱特雷和技术爬爬虾的视频，知道了hugo+github可以搭建一个免费的静态博客，“让文字在互联网永生”，这句话真的深深触动了我，于是就想着开始动手写博客，记录一下自己在学习计算机知识的心路历程。

hugo是一个Go语言开发的博客框架，很多命令都是在命令行执行的，用起来不是很方便，所有就有了写一个Gui界面的想法，但是受限于技术力，自己独立开发也只是想法了，现在有了各种AI大模型，vibe coding，借助于这些工具，重要能够把一些存在于脑海中的idea把它变成现实了。

2026-10-26 更新一：迁移到 Go + Wails，修复文章同步问题

起因

使用中发现问题：在软件的 Articles 页面里编辑文章后，修改的内容、md 文件的 front matter、以及文章所在的一级文件夹名称三者不同步——改了标题，content/post 下那层文件夹还是旧名字；有时正文没动过，保存后 front matter 却被整块重写，自定义字段和注释都丢了。

根因

旧实现（Rust + egui）里，update_article 只重写 index.md，标题变更从来不会去重命名 content/post/<slug>/ 这个 leaf bundle 目录；同时 front matter 是「整块重建」，只保留 date，其它键全部丢弃。

修复与改动

  • 重命名同步：保存时可勾选「保存时同步文件夹名与文件名」，标题变化后按新标题生成 slug 重命名整个 bundle 目录；目标已存在时自动加 -2、-3 后缀，绝不合并两篇文章。
  • front matter 合并而非重建：只替换受管理的键（title / date / draft / tags / categories），未管理的字段、注释、键顺序、原有引号风格全部原样保留，且重复保存两次结果完全一致（幂等）。
  • 先改名后写文件：重命名目录在写入文件之前完成，写失败则回滚目录名，磁盘不会留下半成品状态。
  • 安全边界：章节页（content/post/_index.md 且无同级 index.md）和散落文件（如 content/about.md）永不重命名——重命名章节会毁掉整个站点；页面 bundle 的资源（如 cover.png）随目录一起移动；content/ 之外的路径一律拒绝。
  • 技术栈迁移：整个应用由 Rust/eframe 改写为 Go + Wails v2。本机没有 C 工具链（无 gcc/mingw），Fyne 这类依赖 cgo 的 UI 库编译不过，Wails 是纯 Go + 系统自带 WebView2，go build 即可产出 exe。UI 改为 HTML/CSS/JS，无内存数据库、无本地服务端，直接读写 Hugo 项目文件。
  • 配置写入同样保真：修改 Site Title 等设置时采用 YAML 节点级合并，未知键、注释、标量样式都保留，写入走临时文件 + 原子重命名。

验证

13 个单元测试覆盖上述全部回归面（重命名、冲突后缀、不重命名章节页、资源随移、合并幂等、路径越界拒绝、配置保真），go vet 与 go test 全绿。

2026-10-26 更新二：窗口自适应、构建修复

  • 窗口不再需要最大化：新增 FitWindow，首帧渲染后按当前显示器取 80%×85%（逻辑像素钳制在 900–1600 × 620–1000）并居中，1920×1080 屏幕上启动即 1536×918。此前默认窗口装不下全部界面，必须先最大化。
  • 响应式布局：main 区域独立滚动、状态栏不再是 position: fixed（不再遮挡表格最后一行）、表格固定列宽、长路径自动换行不撑宽页面；新增 900px / 720px / 高度 700px 三档断点——窄窗口下仪表盘自动单列、文章表格自动隐藏「分类」「标签」列，编辑器弹窗可滚动到底。最小窗口从 800×600 调整为 860×560。
  • 批处理脚本乱码修复：run.bat / build.bat 里的中文注释在 936 代码页下被 cmd.exe 拆成碎片当命令执行，报 'ho' 不是内部或外部命令；改为纯 ASCII + CRLF + chcp 65001。
  • 构建标签修复：Wails 用 build tag 选择实现，缺少 -tags desktop,production 时会编译出只弹「Wails applications will not build without the correct build tags」对话框的空壳程序；所有构建命令补齐标签（识别特征：exe 只有约 5 MB 而非 12 MB）。
  • 多语言标题同步：在 Settings 修改 Site Title 时，一并更新 languages.<默认语言>.title，避免 Hugo 优先读取语言级标题导致改动看起来没生效；只在 languages 段已存在时写入，绝不凭空新建。
  • 文档：README / AGENTS / CLAUDE 同步改写为 Go 版，并记录 8 条文章同步不变式作为回归清单。
